# 🏠 DevNest

**開発環境に、ちょっとした「居場所」を。**

DevNestは、Unityで制作しているデスクトップ向け3Dワークスペースです。

3Dの部屋とキャラクターがデスクトップ上に存在し、
Visual Studio Codeなどの開発ツールと連携して、
作業状況に応じたリアクションや休憩のサポートを行うことを目指しています。

> Your development workspace, with a little more life.

## ✨ コンセプト

「ただコードを書く場所」ではなく、
少し戻ってきたくなるような開発環境を作ることがDevNestのコンセプトです。

## 🚧 開発状況

現在開発中です。

### 実装予定

- 🏠 3Dルーム
- 👤 デスクトップキャラクター
- 💻 Visual Studio Codeとの連携
- 🔌 WebSocketによるリアルタイム通信
- 💬 開発状況に応じたキャラクターのリアクション
- ☕ 作業・休憩サポート
- 🎨 部屋やキャラクターのカスタマイズ

## 🛠️ 使用技術

- Unity 6
- C#
- Universal Render Pipeline (URP)
- Visual Studio Code
- WebSocket
